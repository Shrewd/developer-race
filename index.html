Developer Race 🚀

A fun, VS Code themed multiplayer racing game to decide who runs the next Daily Standup!

🎮 How to Play

  1. Open src/race-config.json from the Explorer.
  2. Enter the names of the developers participating.
  3. Adjust the desired race duration.
  4. Click Run Race to start!
